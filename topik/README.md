# 韓檢（TOPIK）分級單字資料

## 檔案

- `topik_vocab.csv` — 網站實際匯入的韓檢單字。欄位和其他課程相同（課程、主題、程度、單字、詞性、
  中文意思、英文解釋、例句、例句中譯），課程是 `TOPIK`，`run.bat` 會用
  `import_sheet.py topik\topik_vocab.csv` 匯入
- 「英文解釋」欄放的是**漢字**（例如 `漢字：學校`），單字卡上會顯示在中文意思下面，
  台灣學生看到漢字很容易記住漢字詞。只有整個字都是漢字、而且同音字沒有別的漢字時才標
- 例句裡的 `[ ]` 標出例句填空要挖掉的地方（例如 `음악을 [들어요].`）。網站顯示例句時會拿掉括號；
  大部分的字程式能自己找到（`vocab_quiz.find_cloze_ko`），只有不規則活用（듣다→들어요）才需要標

## 分級：K1～K6 對應 1～6 級

依兩份韓國官方公開的學習者字表，看每個字被標成哪個程度：

| 等級 | 主題 | 怎麼分 |
|---|---|---|
| 1級 | K1 | 國立國語院列為 A（初級）**而且** TOPIK 列為初級 |
| 2級 | K2 | 其餘 TOPIK 初級的字，以及國立國語院 A 級但 TOPIK 沒列的字 |
| 3級 | K3 | 國立國語院 B（中級）**而且** TOPIK 列為中級以上 |
| 4級 | K4 | 只有其中一份列為中級（國立國語院 B 或 TOPIK 中級以上） |
| 5級 | K5 | 國立國語院 C（高級）**而且** TOPIK 列為中級以上 |
| 6級 | K6 | 只有國立國語院列為 C（高級）的字 |

同一個拼字有好幾個意思（例如 눈 眼睛／雪）時合併成一張卡，等級取最低的那個。
接頭詞、接尾詞、助詞與縮寫形式（그건、뭘…）不收。

## 來源

- 國立國語院（국립국어원）《한국어 학습용 어휘 목록》（韓語學習用詞彙表，2003）
- 國立國際教育院 TOPIK《토픽 어휘 목록 공개 목록》（TOPIK 詞彙公開目錄，2015）
- 兩份表的合併整理參考 [julienshim/combined_korean_vocabulary_list](https://github.com/julienshim/combined_korean_vocabulary_list)
  （程式碼 MIT 授權）

兩份字表都是韓國政府機關公開給學習者使用的資料。本專案只取其中的**單字與等級**，
沒有複製原表的釋義或例句。

## 本專案自己寫的內容

- **中文意思、例句、例句中譯**：全部自行撰寫，例句都是原創的生活短句（初級用敬語 -아요/어요 體），
  沒有引用市售教材或考古題
- **詞性**：由原表的韓文詞性轉成中文（名詞、動詞、形容詞…），一個字有多種詞性時用「／」分隔

修改字卡內容直接改 `topik_vocab.csv` 再雙擊 `run.bat` 即可，匯入只會新增或更新，不會刪除學生進度。
