# 日檢模擬考題庫

每級可以有多回，一回一個純文字檔：第 1 回 `N5.txt`…`N1.txt`，第 2 回起 `N5-2.txt`、`N5-3.txt`…（檔名決定是第幾回），由 `jlpt_mock.py` 讀進來。
同一級每一回的題型、題數、時間都一樣；題目、文章、聽解情境各回不重複。
題目**全部原創**，比照日本語能力試驗的科目、題型與題數編寫，沒有轉錄任何市售教材或考古題。

| 等級 | 科目（分鐘） | 題數 |
|---|---|---|
| N5 | 文字・語彙（20）、文法・読解（40）、聴解 | 21＋22＋24＝67 |
| N4 | 文字・語彙（25）、文法・読解（55）、聴解 | 28＋29＋28＝85 |
| N3 | 文字・語彙（30）、文法・読解（70）、聴解 | 35＋39＋28＝102 |

## 檔案格式

```
@test N5｜日檢 N5 模擬考 第 1 回
@section vocab｜言語知識（文字・語彙）｜20        科目代號｜名稱｜分鐘
# もんだい１｜lang｜                              題組標題｜種類｜旗標
! ＿＿の ことばは ひらがなで どう かきますか。    題組說明
| 文章的一行（讀解）；以 < 開頭的行直接當 HTML（表格）
Q 題幹
> f1: 聽解台詞（n 旁白、f1 f2 女、m1 m2 男）
1 選項
2 正確選項*
= 中文解析
```

- 種類：`lang`（文字語彙文法）、`read`（讀解）、`listen`（聽解），用來分項計分
- 旗標：`spoken`＝選項只用聽的，畫面不顯示（即時應答等）；`cont`＝題號接續上一個題組
- `{漢字|よみ}` 會變成注音假名；`//` 開頭是註解
- 聽解一段話問兩題時，第二題的第一句台詞以「質問２」開頭

## 改完題目

1. `python tools/check_jlpt_mock.py`，**必過**（每題四個或三個選項、剛好一個正解、有解析、正解位置分布）
2. 在櫃台電腦雙擊 `jlpt_audio.bat` 重新產生聽解音檔（`static/audio/jlpt_mock/N5.mp3`…，不進 git）。
   音檔由題庫裡的台詞產生，所以和題目必定一致；台詞沒改的等級會略過

## 計分

交卷後顯示每題正解與中文解析，並依答對比例換算成 180 分的**估計**分數（正式考試用等化計分，這裡只是參考）。
N1～N3 三項各 60 分、各項至少 19 分；N4、N5 是言語知識＋讀解 120 分（至少 38）、聽解 60 分（至少 19）。
合格總分 N1 100、N2 90、N3 95、N4 90、N5 80。
