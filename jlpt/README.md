# 日檢（JLPT）分級單字資料

## 檔案

- `jlpt_vocab.csv` — 網站實際匯入的日檢單字，課程是 `JLPT`，`run.bat` 會用
  `import_sheet.py jlpt\jlpt_vocab.csv` 匯入。欄位和其他課程相同，另外多一欄**讀音**：
  課程、主題、程度、單字、讀音、詞性、中文意思、英文解釋（日檢不用，留空）、例句、例句中譯
- **單字**：一般寫成漢字（学校），習慣寫假名的字就寫假名（ちょっと、ください）；外來語用片假名（カメラ）
- **讀音**：漢字的平假名讀音（がっこう）。同一個寫法有兩種常見唸法時用「／」隔開（明日 → あした／あす），
  單字卡會顯示讀音，播放發音時唸讀音（假名）——語音念漢字偶爾會唸錯，唸假名一定對
- **詞性**：用台灣日文課本的說法：名詞、第一類動詞（五段）、第二類動詞（一段）、第三類動詞（する、来る）、
  い形容詞、な形容詞、副詞、連體詞、接續詞、感嘆詞、代名詞、數詞、片語；名詞可以加する當動詞的寫「名詞・する動詞」

## 例句填空的標記

日文沒有空格分詞，程式沒辦法自己判斷例句裡哪一段是這個字（尤其動詞會變化：飲む → 飲みます）。
所以例句裡用 **`[寫法|讀音]`** 標出要挖掉的那一段，例如：

```
毎朝コーヒーを[飲みます|のみます]。
今日は空が[青い|あおい]です。
[あそこ]に銀行があります。        ← 全是假名的不用寫讀音
```

- 網站顯示例句時會拿掉括號和讀音，學生看到的是「毎朝コーヒーを飲みます。」
- 單字測驗的例句填空，學生打**漢字或假名都算對**（飲みます、のみます）；片假名打平假名也算對
- 動詞、形容詞挖掉的是「活用後的整段」（飲みます、行きました、寒かった），後面的です不挖
- 管理員後台改例句時，如果沒有標、而且例句裡有原字，存檔時會自動幫你標上

## 分級：N5～N1

JLPT 官方從 2010 年改制後**沒有公布正式的分級字表**，各補習班與教材用的分級都是推估。
這裡用最多人使用的 **Jonathan Waller 的 JLPT 字表**（jisho.org 等網站的 JLPT 標記也是用這一份）：

| 等級 | 主題 | 字數 |
|---|---|---|
| N5 | N5 入門 | 665 |
| N4 | N4 初級 | 632 |
| N3 | N3 中級 | 1,613 |
| N2 | N2 中高級 | 1,717 |
| N1 | N1 高級 | 製作中 |

- 同一個字在兩個等級都出現時，放在比較低（簡單）的等級
- 同一個寫法有兩種讀法的（一日 いちにち／ついたち）合併成一張卡，兩種意思都寫在中文意思裡
- 太罕見的寫法換成常見寫法（明い → 明るい、朝御飯 → 朝ご飯）
- 不能單獨當一個字背的接頭詞（お〜、不〜、昨〜、ド〜）不收，改在用到它的單字裡學
- 文語的「〜ずる」動詞收常用的「〜じる」寫法（生ずる → 生じる、論ずる → 論じる），和低一級重複的不再收

## 本專案自己寫的內容

- **中文意思、例句、例句中譯**：全部自行撰寫，用台灣慣用的繁體中文；例句是原創的生活短句，
  難度配合等級（N5、N4 用です／ます體和基本文法），沒有引用市售教材或考古題
- 製作時用程式逐字檢查：讀音和 JMdict 對得上、中文沒有簡體字、例句裡找得到這個字、
  挖空位置沒有切在詞的中間

修改字卡內容直接改 `jlpt_vocab.csv` 再雙擊 `run.bat` 即可，匯入只會新增或更新，不會刪除學生進度。
