# 日檢（JLPT）分級單字資料

## 檔案

- `jlpt_vocab.csv` — 網站實際匯入的日檢單字，課程是 `JLPT`，`run.bat` 會用
  `import_sheet.py jlpt\jlpt_vocab.csv` 匯入。欄位和其他課程相同，另外多一欄**讀音**：
  課程、主題、程度、單字、讀音、詞性、中文意思、英文解釋（日檢不用，留空）、例句、例句中譯
- **單字**：一般寫成漢字（学校），習慣寫假名的字就寫假名（ちょっと、ください）；外來語用片假名（カメラ）
- **讀音**：漢字的平假名讀音（がっこう）。同一個寫法有兩種常見唸法時用「／」隔開（明日 → あした／あす），
  單字卡會顯示讀音，播放發音時唸讀音（假名）——語音念漢字偶爾會唸錯，唸假名一定對
- **詞性**：用台灣日文課本的說法：名詞、第一類動詞（五段）、第二類動詞（一段）、第三類動詞（する、来る）、
  い形容詞、な形容詞、副詞、連體詞、接續詞、感嘆詞、代名詞、數詞、片語；名詞可以加する當動詞的寫「名詞・する動詞」

## 例句填空的標記

日文沒有空格分詞，程式沒辦法自己判斷例句裡哪一段是這個字（尤其動詞會變化：飲む → 飲みます）。
所以例句裡用 **`[寫法|讀音]`** 標出要挖掉的那一段，例如：

```
毎朝コーヒーを[飲みます|のみます]。
今日は空が[青い|あおい]です。
[あそこ]に銀行があります。        ← 全是假名的不用寫讀音
```

- 網站顯示例句時會拿掉括號和讀音，學生看到的是「毎朝コーヒーを飲みます。」
- 單字測驗的例句填空，學生打**漢字或假名都算對**（飲みます、のみます）；片假名打平假名也算對
- 動詞、形容詞挖掉的是「活用後的整段」（飲みます、行きました、寒かった），後面的です不挖
- 管理員後台改例句時，如果沒有標、而且例句裡有原字，存檔時會自動幫你標上

## 分級：N5～N1

JLPT 官方從 2010 年改制後**沒有公布正式的分級字表**，各補習班與教材用的分級都是推估。
起點是最多人使用的 **Jonathan Waller 的 JLPT 字表**（jisho.org 等網站的 JLPT 標記也是用這一份），
再加上補充字，最後全部重新檢查一次分級（見下面「重新分級」）：

| 等級 | 主題 | 字數 |
|---|---|---|
| N5 | N5 入門 | 682 |
| N4 | N4 初級 | 774 |
| N3 | N3 中級 | 2,420 |
| N2 | N2 中高級 | 3,260 |
| N1 | N1 高級 | 2,961 |
| 合計 | | **10,097** |

- 同一個字在兩個等級都出現時，放在比較低（簡單）的等級
- 同一個寫法有兩種讀法的（一日 いちにち／ついたち）合併成一張卡，兩種意思都寫在中文意思裡
- 太罕見的寫法換成常見寫法（明い → 明るい、朝御飯 → 朝ご飯）
- 不能單獨當一個字背的接頭詞（お〜、不〜、昨〜、ド〜）不收，改在用到它的單字裡學
- 文語的「〜ずる」動詞收常用的「〜じる」寫法（生ずる → 生じる、論ずる → 論じる），和低一級重複的不再收

## 補充字（2,667 字）

Waller 字表只有 7,430 字，為了湊到約一萬字，另外從 JMdict 挑出**常用度高（新聞與日常用字前段）、但 Waller 字表沒收**的字：

- 排除接頭／接尾詞、助詞、助數詞、罕見／古語／俚語，以及人名、地名、政黨、官署名這類專有名詞（台灣學生常用的國名、地名如台湾、韓国、東京、北海道保留）
- **依難度放進合適的等級，不是一律放高級**：先看字裡最難的漢字（本字表各級用到的漢字＋KANJIDIC2 舊制級數）和 JMdict 常用度，
  再逐字人工判斷。基礎生活字放低級（顔、父、母、日本語 → N5；野球、台湾 → N4），新聞、商業、法律用語放 N2、N1
- 分級是推估，和市售教材可能差一級；後台可以直接改單字的「主題」換等級
- 中文意思、例句、例句中譯一樣全部自行撰寫，並通過同一套程式檢查

## 重新分級（2026-11）

Waller 字表的 N1、N2 是照舊制 1 級字表來的，裡面混了很多日常字（システム、データ、天才、上司、おはよう），
補充字也有一些放太高。所以把 N1、N2 每個字重新比對：

- **常用度**：wordfreq 的日文字頻（字幕、網路、新聞、維基混合，比只看新聞更接近日常用語）
- **漢字難度**：字裡最難的漢字在 KANJIDIC2 的舊制級數（全部是 4、3 級的簡單漢字才可能放到 N4）
- 外來語、全假名的字另訂門檻；再逐字人工判斷，太書面的（もはや、ないし、行政）留在 N2，
  很日常的（俺、携帯、天井、パトカー）放 N3，最基礎的（おはよう、ありがとう、日本、メニュー）放 N4、N5

結果 1,240 字換等級：N1 → N2 707 字、N1 → N3 292 字、N2 → N3 186 字、N1／N2 → N4 48 字、
N2／N3 → N4、N5 7 字（N3 裡的ありがとう、日本、円、ゲーム、カード）。
移到 N4、N5 的字例句全部改寫成です／ます體的簡單句子；移到 N3 的字原本例句就是簡單短句，沒改。
完整清單在專案檔案的 `jlpt/日檢重新分級清單.csv`。

換等級不會多出重複字，學生的學習紀錄也跟著字走：`import_sheet.py` 找不到同主題的字時，
如果這個課程只有一筆同拼字的字，就把那筆搬到新主題。
